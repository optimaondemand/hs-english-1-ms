## Relationship to `hs-english-1`

`hs-english-1` serves the **Florida** version of this course (Canvas course 4).
This repo is a separate copy so a Mississippi-only revision cannot alter the
Florida course, and vice versa. The two started identical; they are expected to
diverge as diocesan content is layered in.

The Mississippi diocesan standards are Common Core 9-10 essentially verbatim.
Semester 1 coverage is woven into existing lessons as additive sections — there
are no separate MS-designated items and no extra gradebook columns in Modules 1-4.

Source of truth for content is the course folder in OneDrive
(`9th Grade ELA_Development`), not this repo. Push from there.

`.nojekyll` is present on purpose: these are complete static HTML documents and
must be served without Jekyll processing.
